# Marketing B2B Dashboard

Interactive HTML dashboard (self-contained, Chart.js via CDN).

- Data: 20 878 rows, Sep 2025 - Jul 2026
- Metric selector on the monthly evolution chart (Dispatches, SQL, Orders, Placements, Revenue)
- Scorecard comparisons: MoM / QoQ / YoY
